== Description ==
Freedomology is a base skeleton WordPress plugin designed to serve as a foundation for custom code development. It provides a clean, minimal structure for adding custom functionalities to WordPress sites efficiently.

== Installation ==
1. Upload the `freedomology` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Start adding your custom code to the plugin structure.

== Frequently Asked Questions ==
= Can I use this plugin as a base for commercial projects? =  
Yes, Freedomology is licensed under GPLv2 or later, allowing you to use it in both personal and commercial projects.

= Does this plugin add any functionality out of the box? =  
No, Freedomology is a minimal skeleton meant for developers to build custom functionalities.
